# 港股沽空监控（hk_short 模块）设计文档

日期：2026-09-21
状态：数据源已冻结（见 §5.1 与 `docs/港股沽空/source-validation.md`），市场层口径调整为"股票口径为主"已经用户确认，待实施

## 1. 背景与目标

现有 `flow_dashboard` 是 A股资金流单页监控（ETF资金流/两融/衍生品基差/月度）。本设计在其基础上新增**港股沽空监控**模块。

核心诉求（用户原话）："每天拉新数据，给我一个港股市场空头状态的结论，数据也可以展示一下。"

分析方法论遵循用户提供的沽空分析规范，核心原则：

- **Gross Short Flow ≠ Net Short Position Change**：每日沽空成交额是流量，不能直接推断净空仓变化
- **存量定方向，流量看强度，价格看结果，成交量看参与度**
- 判断优先级：周度未平仓淡仓Δ → 沽空额异常 → SSR 历史分位 → 价格 → 量 → ETF/对冲干扰
- 状态结论由**纯规则引擎**生成（确定性、可测试），不使用 LLM 生成结论

## 2. 盘面范围

- **市场层面**：全市场汇总指标 + 状态结论（本模块的核心产出）
- **个股层面**：固定 watch list 的逐日明细表 + 当日沽空额 TOP20 榜单
- **不做**：全市场逐股深度跟踪、交易建议

## 3. 前端方案：同一 HTML 内 tab 分页

`theme.py` 的 `build_html_skeleton()` 增加 `tabs` 参数：

- 顶部一级导航：「A股资金流 | 港股沽空」，默认停在 A股
- 每个 tab 一个容器，内含各自的 section-nav 锚点导航
- ~15 行原生 JS 切换，URL 记住当前 tab，刷新不跳回
- A股页现有 DOM 与行为不变，只是包进 tab 容器
- 任一侧数据缺失：对应 tab 显示"数据待更新"横幅，不影响另一 tab

选择该方案（而非独立 HTML / 长滚动追加板块）的理由：渲染从 parquet 缓存确定性重放，港股数据源故障不会拖垮 A股页发布；单一 URL 与发布产物；为后续第三个市场留扩展口。

## 4. 港股 tab 页面结构（自上而下）

### 4.1 空头状态结论卡（最重要，置顶）

- 一句话市场结论，规则引擎输出，枚举值：
  - 空头净加仓迹象明显 / 空头净回补迹象明显 / 沽空活跃但净仓变化有限 / 多空分歧扩大 / 暂时无法确认
  - SFC 最新应公布周数据未覆盖时，统一加"·SFC待确认"后缀；不得把尚在正常发布宽限期内的数据标为缺失
- 三个副指标：今日全市场沽空额（vs 前20日均值倍数，股票口径并标注）、市场加权 SSR（前60日历史分位，股票口径并标注"不含 ETF/ETP"）、最新 SFC 市场须申报淡仓比例变化
- ETF 沽空占比过高时（阈值见 §6），结论下方注明"总沽空增加或主要来自指数对冲，不宜直接解读为个股看空增强"

### 4.2 市场总览图

- 总沽空额 + 市场加权 SSR 双轴时序，叠加恒指/恒生科技走势（主序列为股票口径，标注口径；全口径 SSR 序列累积满 60 个观测后并行展示）
- 每日注记 HKEX 全口径总沽空额与 ETF 占比
- 目的：一眼看出"沽空放大时价格怎么走"

### 4.3 个股逐日明细表（列格式与用户示例一致）

- 未平仓两列**只在 SFC 周度报告日有值**（稀疏列，与示例一致）

## 5. 数据链路

新增 `src/flow_dashboard/data/hk_short/` 子包，loader 遵循现有统一契约（读 parquet 缓存 → 拉增量 → merge → 写回 → PIT 过滤）。缓存落 `data/hk_short/cache/*.parquet`。所有数据保留 `source_date`、`available_at`、`first_observed_at`、`fetched_at`、`source`、`source_version` 与质量标记；过滤条件始终为 `available_at <= as_of`。

| 数据 | 来源（已冻结，见 `docs/港股沽空/source-validation.md`） | 频率 | 滞后 |
|---|---|---|---|
| 个股逐日卖空成交 + 日线（价、量、额、总股本） | 主源东财 sellshort（HTML 分页）+ push2his/push2；备源 HKEX dayquot（切换条件：连续 3 次重试失败或对账差 >0.5%） | 每交易日 | T日盘后 |
| 全市场逐证券每日卖空额（**股票口径**，TOP 榜、SSR 分位的历史基础） | 主源东财 sellshort（~1 年历史）；对账源 HKEX dayquot | 每交易日 | T日盘后 |
| 全口径逐证券卖空（含 ETF/ETP/REIT）与同证券成交额 | HKEX dayquot 归档（滚动 ~41 交易日）+ ashtmain 当日文件；T+1 抓取时以 PREVIOUS DAY'S ADJUSTED 段覆盖 T-1 修正 | 每交易日 | T日盘后 |
| 个股周度须申报淡仓（SFC 口径，含股数/金额） | SFC 官网 CSV（权威独占，`available_at` = 响应 Last-Modified） | 每周（截至周最后交易日） | position_date + 7 天（周五 15:00-16:40 HKT） |
| ETF/REIT 证券主表 | HKEX ListOfSecurities.xlsx（每日更新，每周抓取；ETF 集合 = Category 为 Exchange Traded Products） | 每日更新 | T日 |
| 恒指、恒生科技指数日线 | 东财 push2his（`100.HSI` / `124.HSTECH`；个股与 ETF 用 `116.XXXXX`） | 每交易日 | T日盘后 |

**市场层指标口径（2026-09-21 经用户确认冻结）**：市场加权 SSR、日/周沽空强度、前 20 日均值倍数一律使用**股票口径**——分子 = Σ东财当日沽空金额，分母 = Σ东财当日总成交金额（同页两列，天然同口径，历史 ≥1 年）。页面相应位置标注"股票口径，不含 ETF/ETP"；同屏每日注记 HKEX 全口径总额与 ETF 占比；全口径 SSR 序列自上线起每日累积，满 60 个观测后在市场总览图并行展示。ETF 干扰证据（§6.3 第 6 步）用 HKEX 全口径当日值计算。watch list 中 ETF（2800/3033）的卖空数据来自 HKEX dayquot（东财不含 ETF），上线初期仅能回补 ~41 个交易日，其 SSR 60 日分位显示"样本不足"直至累积满 60 个观测。TOP20 榜单为股票口径。

要点：

- **个股 SSR 统一使用金额口径**：`卖空金额 / 成交额`。卖空历史来自全市场逐证券日频数据集（股票口径）；watch list 持续维护行情历史。当证券首次进入当日 TOP20 候选集时，按需回补至少 80 个交易日的成交额、价格和成交量，确保可计算 60 日分位；不拉取全市场完整行情
- 东财 sellshort 的"最新价"列是查询时点价而非历史收盘价，任何历史价格一律来自行情接口；金额列需解析万/亿后缀；东财接口有限流，loader 必须 retry + 指数退避
- 每个面板标注"数据截至"日期
- 个股未平仓周环比 = 最新 `position_date` vs 上一 `position_date`；用 `淡仓股数 / 同期总股本` 比较，并对拆股、合股、供股等公司行动调整。中间日频数据不参与淡仓比较
- SFC 数据同时保存 `position_date`、页面实际公布时间 `published_at` 和首次抓到时间 `first_observed_at`；`available_at = published_at`，无法可靠取得网页时间时使用 `first_observed_at`，绝不由报告日加固定天数倒推
- SFC 数据是超过法定门槛的**须申报净淡仓**，不是全市场完整空仓；页面和结论统一使用“须申报淡仓”，不得简称为“全市场空仓”
- 抓取失败重试后仍失败：保留缓存旧数据 + 页面挂"数据待更新"，不阻塞发布

### 5.1 实施前数据源验证门（source spike）——已完成，2026-09-21 冻结

只读验证已完成，结果与全部实测细节（URL、响应样例、解析坑、限流、对账数字、SFC 公布时间）见 `docs/港股沽空/source-validation.md`。冻结要点：主源东财（股票口径，~1 年），对账源 HKEX dayquot（全口径，滚动 ~41 交易日），SFC CSV 权威独占（历史至 2012），ETF 主表 ListOfSecurities.xlsx。对账门通过：2026-09-18 共同证券 742 只总额相对差 0.000001%，随机 20 只最差 0.089%。原验证清单：

- HKEX/东方财富候选接口的 URL、响应样例、字段映射、代码格式、历史最早日期、分页与限流
- 每个数据集的主源、备源及切换条件；主备源同日总额和随机 20 只证券对账，金额相对差异须不超过 0.5%，否则禁止自动切换
- 日频数据实际公布时点，以及 `available_at` 的取值规则
- SFC CSV 的下载方式、`position_date`、实际 `published_at`、证券进入/退出报告的语义
- ETF/REIT 分类所用证券主表及生效日期；ETF 占比只汇总全市场 ETF 集合，watch list ETF 是该集合的子集，不重复相加

若任一核心数据集无法获得至少 80 个交易日历史或稳定增量接口，停止实施并回到本设计调整，不在 loader 中临时更换口径。（验证结果：HKEX 全口径仅 ~41 交易日，触发了本条；经用户确认按 §5 冻结的"股票口径为主 + 全口径累积并行"方案调整，全口径数据集仅用于当日 ETF 证据与展示注记，不承担历史分位职责，故不再阻塞实施。）

## 6. 指标与状态引擎（`indicators/hk_short*.py`，纯规则）

### 6.1 指标

- 个股 `SSR_t` = 个股卖空金额 / 个股总成交额；市场 `SSR_t` = 全市场卖空金额 / 同口径市场总成交额。分子、分母必须覆盖相同市场板块和证券类别
- 日沽空强度 = 当日卖空额 / 前 20 个交易日卖空额均值（均值不包含当日）
- 周沽空强度 = 最近 5 个交易日卖空额合计 / 此前 12 个非重叠 5 日窗口均值；不足 12 个完整窗口则该证据记为 unavailable
- SSR 60日历史分位使用前 60 个有效交易日，不包含当日；至少 20 个有效观测才输出分位，否则显示“样本不足”且不参与状态判定
- 参与度倍数：个股使用当日成交额 / 前 20 日成交额均值；市场使用同口径市场总成交额 / 前 20 日均值
- 个股 SFC 指标 = 经公司行动调整后的 `淡仓股数 / 总股本` 周环比及 4 周斜率
- 市场 SFC 指标仅在连续两期均出现且公司行动数据完整的可比证券集合上计算：
  - `market_short_ratio = Σ须申报淡仓市值 / Σ对应证券市值`
  - `market_short_ratio_delta_bps` 为连续两期比例差（基点）
  - `short_breadth` 为淡仓占比上升证券数 / 可比证券数
  - 同时显示可比证券数和上一期 SFC 报告覆盖市值比例；可比证券少于 100 只或覆盖市值低于上一期报告集合的 80% 时，市场 SFC 证据记为 unavailable

### 6.2 初始阈值与方向定义

阈值集中在 `config.py`，首版冻结如下；校准只能修改配置与对应测试，不改变状态优先级：

| 证据 | 正向/高 | 负向/低 | 中性 |
|---|---|---|---|
| 市场淡仓变化 | `delta >= +3bp` 且 `breadth >= 55%` | `delta <= -3bp` 且上升 breadth `<=45%` | 其余可用值 |
| 个股淡仓变化 | 淡仓占总股本比例增加 `>=5bp` | 减少 `>=5bp` | 绝对变化 `<5bp` |
| 沽空额高 | 周沽空强度 `>=1.25` | — | `<1.25` |
| SSR 高分位 | 历史分位 `>=80%` | — | `<80%` |
| 价格方向 | 5日收益率 `>=+1%` | 5日收益率 `<=-1%` | 中间区间 |
| 参与度放大 | 参与度倍数 `>=1.20` | — | `<1.20` |
| ETF 干扰 | ETF 沽空额 / 全市场沽空额 `>=30%` | — | `<30%` |

市场价格方向取恒指与恒生科技指数 5 日收益率的等权平均；一个上涨、一个下跌且等权平均落入中性区间时记为中性。除零、缺分母、无限值一律转为 unavailable，不视为 0。

### 6.3 市场状态判断顺序（硬编码）

1. SFC 市场须申报淡仓比例 Δ 与扩散度（若已超过预期公布宽限期仍未公布 → 结论降级"·SFC待确认"）
2. 最近 5 个交易日沽空额是否异常（vs 历史非重叠 5 日窗口）
3. SSR 是否处于历史高分位
4. 价格方向（恒指/恒生科技）
5. 参与度是否放大
6. ETF 沽空占比检查：全市场 ETF 沽空额占比达到 30% 时触发"指数对冲"提示

SFC 预期公布日使用香港交易日历计算：`position_date` 后第 5 个香港交易日结束为宽限期。宽限期内沿用最新已公布一期并显示其报告日，不加“待确认”；超过宽限期仍缺新一期时，SFC 证据记为 unavailable，并添加后缀。实际 `published_at` 仍是 PIT 唯一依据。

### 6.4 状态矩阵（市场与个股共用逻辑，分别输出）

| 状态 | 组合 |
|---|---|
| 空头净加仓迹象明显 | 淡仓↑ + 沽空额高 + SSR高分位 + 价跌 + 参与度放大 |
| 多空分歧扩大 | 淡仓↑ + 价涨（空头逆势加仓） |
| 空头净回补迹象明显 | 淡仓↓ + 价涨 + 参与度放大（沽空额高也可并存，注明） |
| 沽空活跃但净仓变化有限 | 沽空额高 + SSR高 + 淡仓Δ≈0 |
| （跌但空仓减）| 价跌 + 淡仓↓ → 注明"下跌压力或来自长仓卖盘而非新增空头" |
| 暂时无法确认 | 证据互相矛盾或不足 |

状态按表格自上而下匹配，首个命中即返回；未命中返回“暂时无法确认”。“跌但空仓减”不是第六种状态，而是附加说明。任何需要淡仓方向的状态在 SFC 证据 unavailable 时均不得输出“净加仓/净回补明显”，只能返回“暂时无法确认·SFC待确认”。首版不输出 "short squeeze"；待未来另行定义强证据规则后再加入，避免不可测试的自由表述。

## 7. 调度与发布

- 新 launchd plist `com.ygr.hk-short.eod`：周一至周五 18:45（北京=香港时间），runner 内部使用香港交易日历短路休市日
  - 拉 HKEX 汇总 + 个股日线 + SFC（有新周报则抓）→ 获取现有 `RUNNERS_LOCK` → 整页重渲染 → 调用现有 `publish_archive()` 发布归档、manifest、`latest.html` 和 `current.html`
- A股 19:30 runner 不动；它重渲染时从 parquet 缓存把港股 tab 一起带上
- 港股休市日（A股开市）：runner 照跑，数据无增量即跳过渲染
- 港股 runner 与 A股 runner 必须共用 `config.RUNNERS_LOCK`；获取锁失败时保留现有页面并记录 `skipped_due_to_lock`，不得绕过锁单独替换 `latest.html`
- 组合报告保存 `ashare_data_date` 与 `hk_data_date` 两个日期；顶层归档文件名沿用触发本次发布的报告日期，各 tab 和 manifest 分别展示自己的数据日期与 stale 状态，禁止把港股旧日期标成当日

## 8. 测试

- 状态引擎单测：§6.4 每个状态构造合成数据用例；阈值等号边界；冲突时首个匹配；SFC unavailable 降级；ETF 干扰场景
- 指标边界：除零、历史不足 20/60 日、周窗口不足 12 个、次新股、公司行动、SFC 样本进入/退出、覆盖率不足
- loader 增量合并与 PIT 过滤测试（仿现有 test 模式）
- PIT 回放测试：在 `published_at` 前看不到该期 SFC 数据，在公布后可见；正常宽限期不挂待确认，超期才挂
- TOP20 首次入榜测试：自动回补 80 个交易日行情并计算 60 日 SSR 分位；回补失败则显示“样本不足”，不伪造分位
- 发布集成测试：两个 runner 共用锁；完整发布同时更新 archive/manifest/latest/current；两市场日期分别呈现
- 真实抓取冒烟测试挂 `@live` 标记
